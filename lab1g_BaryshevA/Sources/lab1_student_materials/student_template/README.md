# Стартовый проект студента

Скопируйте каталог и переименуйте его в `lab1_<Фамилия>`.

## Первичная настройка

1. Укажите свой вариант в `main.py` и `report.md`.
2. Обновите зависимости и зафиксируйте их:

   ```bash
   uv lock --upgrade
   uv sync --frozen
   ```

3. Реализуйте прямой расчёт, выбор проверочных точек и построение рисунков.
4. Удалите шаблонный рисунок и замените его собственными.
5. Соберите `report.pdf` из `report.md` выбранным инструментом.

## Проверка перед архивированием

```bash
uv sync --frozen
uv run python main.py
```

Команда должна создать все изображения, на которые ссылается `report.md`. Затем запустите преподавательскую проверку структуры, если она выдана вместе с заданием:

```bash
uv run python ../teacher_tools/precheck_submission.py . --run
```

Шаблон намеренно не содержит реализации баллистической задачи и не задаёт формулу штрафа. Эти решения являются частью работы.
