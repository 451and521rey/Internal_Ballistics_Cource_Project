# Каталог рисунков

Все файлы в этом каталоге должны создаваться командой:

```bash
uv run python main.py
```

Не добавляйте сюда вручную исправленные копии графиков. Подписи, единицы, легенды и границы формируются кодом. Файл `template_check.png` из стартового проекта нужно удалить после появления собственных рисунков и удаления ссылки на него из `report.md`.
