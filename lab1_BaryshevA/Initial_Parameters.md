# Исходные данные варианта № 36

## Основные параметры

| Параметр | Обозначение | Значение |
|---|---:|---:|
| Калибр орудия | $d$ | 85 мм |
| Масса снаряда | $q$ | 9,54 кг |
| Требуемая дульная скорость при нормальных условиях | $v_{pm}$ | 650 м/с |
| Тип орудия | — | нарезное (НР) |
| Математическая модель внутренней баллистики | — | нульмерная модель (НМ) |

## Целевой критерий

Критерий варианта — объём канала ствола вместе с каморой $W_{pm}$.
Целевое направление — **минимизация** $W_{pm}$.

## Ограничения

### Общие ограничения

| Ограничение | Условие |
|---|---:|
| Максимально допустимое среднебаллистическое давление при нормальных условиях | $p_m \le 330$ МПа |
| Максимальная длина ведущей части канала ствола | $l_m \le 60d$ (5,10 м при $d = 85$ мм) |

### Индивидуальные ограничения варианта № 36

| Ограничение | Условие |
|---|---:|
| Минимальная дульная скорость при начальной температуре $-50\,^{\circ}\mathrm{C}$ | $v_{pm,-50} \ge 570$ м/с |
| Максимально допустимое дульное среднебаллистическое давление при начальной температуре $+50\,^{\circ}\mathrm{C}$ | $p_{mz,+50} \le 170$ МПа |

## Общие условия расчёта

- Давление воспламенителя для лабораторной работы: $p_{ign\_0}=5$ МПа.
- Воспламенитель — порох марки «ДРП».
- Для нарезного орудия давление форсирования принимается равным 30 МПа.
- Площадь поперечного сечения канала ствола нарезного орудия определяется как
  $S=0{,}26\pi d^2$.
- Марка пороха или состав смеси порохов выбираются при формировании исследуемого баллистического решения.
